规则

先在 Z ≤ 0 的任意整数格点放置棋子，或无限填满整个下半空间。开始后，沿 ±X、±Y、±Z 任一方向，跳过相邻的一枚棋子，落在紧接着的空格上。被跳过的棋子移除，每一步减少一枚棋子。

三维康威跳棋可以通过有限步骤抵达第 7 层，无法抵达第 8 层。这是规则产生的数学边界；游戏没有把上方格点封锁。

把三维拆成可操作的切片

XZ 纵切按 Y 分层，XY 横切按 Z 分层。使用工作切片里的 XZ / XY 按钮切换方向；有选子时，新面经过选中棋子，无选子时经过视图中心最近的整数层。相机中心、角度和缩放保持不变，棋盘不会归位；需要更容易点选时，再点「正视」。实心棋子属于当前面，XZ 中蓝色圈表示 Y− 侧、紫色表示 Y+ 侧；XY 中对应 Z− 和 Z+ 侧；远侧虚线、近侧实线随镜头变化。加减按钮、滑条与数字输入沿当前 Y 或 Z 切层，整个棋盘仍然存在。高度始终沿 Z 轴计算。

选子后，六个方向的亮色落点都可以直接点击，包括跨工作面的跳跃。X 为橙色、Y 为蓝色、Z 为绿色，与方向按钮一致。落点按视图深度排列，被前方落点明显遮挡的后方圆会变灰，旋转使其完全露出后即可点击；也可直接使用六向按钮。自动跟随默认开启，关闭后跳跃和撤回保持当前切片与视图。侧视时仅暂停普通摆子和选子，可见落点仍可点击；点「正视」可恢复工作面操作。

键鼠 / 触控

  • 轻点操作格点；拖动旋转。切到「平移」可用单指或左键移动工作区域。
  • 鼠标右键拖动旋转，Shift + 拖动或中键拖动平移，滚轮缩放。
  • 触屏双指平移、捏合缩放，抬起一指不会误落子。
  • 聚焦棋盘后：方向键移动当前面光标（左右 X，上下为 Z 或 Y），空格 / 回车操作；V 切换 XZ / XY，Q / E 或 PageUp / PageDown 切当前 Y / Z 层；W A S D 平移，F 正视，H 归位，+ / − 缩放，Esc 取消。

可以逐步撤回、重玩，或回到开局蓝图编辑。全部代码、音效和视觉资源均在本地；无需联网、账号或安装依赖。游戏不保存对局与偏好，刷新或关闭页面会重置。
