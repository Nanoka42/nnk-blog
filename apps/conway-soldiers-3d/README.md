# 康威跳棋 3D

一个兼顾键鼠和触屏的三维康威跳棋游戏。在 $Z\leq0$ 的半空间自由摆子，沿 $\pm X$、$\pm Y$、$\pm Z$ 六个方向跳吃，尝试向上推进到第 $7$ 层。

游戏提供两种可随时切换的工作面：**XZ 纵切面**用于观察高度与沿 Y 的邻层，**XY 横切面**用于查看同一高度内的布局与沿 Z 的邻层。XY 也便于检查绕 Z 轴旋转后相似的局部结构。切换保留摄像机中心、旋转和缩放；有选子时，新工作面经过该棋子并保留选择，无选子时取最接近视图中心的整数切片。

本项目可独立运行；[二维版本](https://github.com/Nanoka42/nnk-blog/tree/main/apps/conway-soldiers) 是并列的独立项目。博客入口为 [康威跳棋 3D](https://nanoka.tv/projects/conway-soldiers-3d/)，两个游戏的说明窗口可以互相跳转。

## 本地运行

推荐安装 Node.js **24 或更新版本**，便于同时运行博客项目；本游戏单独运行的最低要求是 Node.js **20.11**。没有第三方运行依赖，不需要 `npm install`。在本目录打开 PowerShell：

```powershell
npm run dev
```

打开终端打印的地址，默认是 [http://127.0.0.1:5318/](http://127.0.0.1:5318/)。默认端口不可用时自动选择空闲端口；显式设置 `PORT` 时严格使用指定端口。`npm start` 与 `npm run dev` 相同，按 `Ctrl+C` 停止服务。

如需让同一局域网的手机访问：

```powershell
$env:HOST = '0.0.0.0'
npm run dev
```

手机打开 `http://电脑的局域网IP:5318/`，端口以终端输出为准。默认仅监听本机 `127.0.0.1`。需要指定端口时，可先设置 `$env:PORT = '5319'`；这些环境变量会影响当前 PowerShell 窗口中随后启动的服务。

博客根项目要求 Node.js **24 或更新版本**并安装根目录依赖；集成开发与部署见[博客仓库说明](https://github.com/Nanoka42/nnk-blog/blob/main/README.md)。

## 第一次游玩

1. 游戏默认进入空白蓝图。在当前工作面点击 $Z\leq0$ 的格点摆子，或选择“无限填满”。
2. 用 **XZ / XY** 按钮选择方向。加减按钮、数字输入和附近切片滑条在 XZ 模式修改 **Y**，在 XY 模式修改 **Z**。
3. 切换后保留原视角。如果新工作面接近侧视，点击“正视”后继续摆子；也可以自行旋转。
4. 点击“开始跳棋”，选中当前面的一枚实心棋子，再点亮起的落点或六向按钮跳跃。
5. 灰色落点被其他落点遮挡；旋转使它完全露出，或使用对应方向按钮。

蓝色空心圈表示当前切片的法向负侧，紫色表示正侧：XZ 对应 Y− / Y+，XY 对应 Z− / Z+。较远侧使用虚线，较近侧使用实线。X、Y、Z 跳跃落点分别为橙、蓝、绿色，始终表示世界坐标轴。

XY 当前切片的 X、Y 两条坐标轴使用同样明亮的辅助线，交点就是 $(0,0,z)$；即使填满棋子，也可沿棋子之间的轴线辨认原点位置。

“自动跟随”默认开启。跳跃或撤回时，XZ 模式跟随 Y 切片，XY 模式跟随 Z 切片；必要时调整中心，保留旋转和缩放。关闭后，跳跃和撤回保持当前切片与视图。手动导航仍然可用。

## 操作速查

| 操作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 摆子、选子 | 左键轻点当前工作面 | 单指轻点当前工作面 |
| 旋转视角 | 默认左键拖动；右键拖动始终旋转 | 默认单指拖动 |
| 平移工作区域 | 切换“平移”后左键拖动；Shift + 拖动或中键拖动 | 切换“平移”后单指拖动；双指拖动 |
| 缩放 | 滚轮或缩放按钮 | 双指捏合或缩放按钮 |
| 切换工作面方向 | XZ / XY 按钮 | 相同 |
| 切换 Y / Z 切片 | 加减按钮、数字输入、附近切片滑条 | 相同 |
| 六向跳跃，包括跨切片 | 点击亮色落点或六向按钮 | 相同 |
| 对准当前工作面 | “正视”按钮，保留中心和缩放 | 相同 |
| 回到原点附近与初始视角 | “归位”按钮，保留工作面方向 | 相同 |

普通摆子和选子只作用于**当前工作面**；邻层虚影用于空间参考，不接收或阻挡点击。光标经过前方或后方的虚影时，仍按当前切片上的格子悬停、放子、取子或选子；邻层显示范围不会改变点选结果。视角接近侧视时，画布显示琥珀色边框和醒目提示，暂停普通格点操作；仍可拖动调整视角、点击“正视”，或操作已选棋子的可见落点。切换 XZ / XY 保留选子；修改切片坐标、归位和坐标定位会取消选子。

用 `Tab` 聚焦棋盘，或先点击棋盘，即可使用以下按键。输入框、按钮拥有焦点时保留其通常的键盘行为。

| 按键 | 操作 |
| --- | --- |
| ← / → | 光标沿 X 轴减一 / 加一 |
| ↑ / ↓ | XZ 模式沿 Z 轴加一 / 减一；XY 模式沿 Y 轴加一 / 减一 |
| 空格 / Enter | 操作光标所在格点 |
| V | 切换 XZ / XY，保留视角与选子 |
| Q / PageUp | 当前切片坐标减一：XZ 为 Y，XY 为 Z |
| E / PageDown | 当前切片坐标加一：XZ 为 Y，XY 为 Z |
| W / A / S / D | 平移视图 |
| + / =，− / _ | 放大 / 缩小 |
| F | 正视当前工作面 |
| H | 归位，保留工作面方向 |
| Esc | 取消选子和光标；弹窗中关闭弹窗 |

正视 XZ 时，+X 向右、+Z 向上；正视 XY 时，+X 向右、+Y 向上，Z 是跨切片方向。**游戏高度始终是 Z**。XY 的 $Z>0$ 切片可以游玩和查看，但不能作为蓝图摆子区域。

桌面的“坐标定位”可输入 X、Y、Z，使当前方向的工作面经过指定格点，将其居中并正视。相机、邻层与落点规则详见[交互设计](./docs/INTERACTION.md)。

## 规则与对局

每一跳沿某个坐标轴移动两格：起点与中间一格有棋子，落点为空。跳跃后移除中间棋子，总数减少一枚；不允许斜跳。每次跳跃结束都会清除选择。

“撤回一步”恢复上一步；“重玩这局”恢复开局布局；“回到蓝图”恢复开局并允许重新编辑。替换已有布局或清除已走棋谱前，会显示确认弹窗。切换工作面不会修改棋盘、历史或开局快照。

“最高层”记录当前棋谱曾到达的最高 Z，撤回时相应恢复。有限开局显示当前 / 开局棋子数；无限开局显示下方空格与上方棋子数。

第 7 层可达、第 8 层不可达来自数学规则，引擎没有额外禁止向第 8 层移动。证明与一手文献出处见[数学说明](./docs/MATHEMATICS.md)。

## 离线方式与数据

代码、图形和音效全部来自本地，没有 CDN、在线字体、后端、账号或网络服务依赖。**启动本地 HTTP 服务后，没有互联网也能游玩。** 手机访问仍需要能够连接运行服务的电脑。

请通过 HTTP 打开。浏览器对 ES Module 的限制意味着不能双击 `index.html`、使用 `file://` 运行。项目没有 Service Worker 或离线安装缓存；关闭本地服务后，不能依靠离线缓存重新打开游戏。

对局和声音偏好只保存在当前页面内存中，刷新或关闭页面会重置。声音默认开启，在第一次用户操作后解锁；浏览器无法播放声音时不影响规则和操作。

## 构建与检查

在本目录运行：

```powershell
npm test
npm run build
npm run preview
```

`npm test` 只运行三维版本测试。`npm run build` 清空并重新生成本项目的 `dist/`，复制页面、源码与本地音效；`npm run preview` 用同一本地服务提供该目录。预览前停止占用同一端口的开发服务，或设置另一个 `PORT`。生成的静态文件无需服务端运行逻辑。

博客根构建会重新生成本项目产物并集成，无需预先手动构建子项目。博客根目录 `npm run test:browser` 在已有根构建上运行桌面、平板、手机视口和生产预览回归；准备步骤见[博客仓库说明](https://github.com/Nanoka42/nnk-blog/blob/main/README.md)。覆盖与真机测试边界见[验证记录](./docs/VALIDATION.md)。

本项目的 `dist/`、博客根目录的 `public/play/` 和 `.generated/` 均为生成内容，不直接编辑或提交。独立运行时，说明窗口的版本链接跳到正式博客；博客集成时使用同源项目地址。

## 代码结构

```text
index.html                    游戏入口、控制面板与弹窗
src/
  engine.js                   三维规则、无限半空间、快照与历史
  camera.js                   世界相机、XZ/XY 工作面、投影与可见窗口
  gestures.js                 点击 / 拖动分离和多指导航状态
  renderer.js                 Canvas 当前面、邻层、坐标与六向落点
  app.js                      界面状态、切面、键盘、确认与自动跟随
  styles.css                  桌面 / 移动布局、安全区和弹窗样式
  audio.js                    本地音效、静音与不可用时的降级
  webmcp.js                   自动检测支持的可选浏览器代理接口
  mark.svg                    本地矢量标志
sounds/                       本地 WAV 音效
scripts/                      无依赖本地服务与静态构建脚本
tests/                        三维版本测试
docs/                         数学、交互与验证说明
```

每帧最多采样当前工作窗口的 $31\times31$ 个格点及前后合计最多 5 个切片，两种模式共用这一上限。旋转只改变窗口投影；平移、缩放、窗口尺寸与工作面方向决定格点范围。窗口外的棋子仍参与规则。相机和定位控件有约 $\pm10^6$ 格的工程边界，规则引擎使用更大的 JavaScript 安全整数坐标范围，均不把可达高度硬编码为 7。
