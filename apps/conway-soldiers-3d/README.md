# 康威跳棋 3D

一个兼顾键鼠和触屏的三维康威跳棋游戏。你可以在 $Z\leq0$ 的半空间自由摆子，沿 $\pm X$、$\pm Y$、$\pm Z$ 六个方向跳吃，尝试向上推进到第 $7$ 层。

游戏采用“**XZ 工作面 + 前后邻层 + 六向可点击落点**”的交互。蓝色圈表示较小 Y 一侧，紫色圈表示较大 Y 一侧；较远的一侧使用虚线，较近的一侧使用实线，线型随镜头变化。选中棋子后，直接点击任意可见的六向落点即可跳跃；X、Y、Z 落点分别使用橙、蓝、绿色，与方向按钮一致。明显被前方落点遮挡的圆变成灰色虚线，完全露出后恢复。自动跟随默认开启，也可以关闭以保持当前切片和视图。

本项目位于博客仓库的 `apps/conway-soldiers-3d/`，可独立运行；[二维版本](../conway-soldiers/) 是并列的独立项目。博客正式入口为 [康威跳棋 3D](https://nanoka.tv/projects/conway-soldiers-3d/)，两个游戏的说明窗口可以互相跳转。

## 本地运行

需要 Node.js **20.11 或更新版本**。项目没有第三方运行依赖，不需要执行 `npm install`。

在本项目目录 `apps/conway-soldiers-3d/` 打开 PowerShell，运行：

```powershell
npm run dev
```

在浏览器打开终端打印的地址，默认是 [http://127.0.0.1:5318/](http://127.0.0.1:5318/)。默认端口不可用时，会自动选择空闲端口；显式设置 `PORT` 时则严格使用指定端口。`npm start` 的作用相同。按 `Ctrl+C` 停止本地服务。

如需让同一局域网中的手机访问：

```powershell
$env:HOST = '0.0.0.0'
npm run dev
```

手机打开 `http://电脑的局域网IP:5318/`。默认只监听 `127.0.0.1`，即仅允许本机访问。可以通过 `PORT` 更换端口：

```powershell
$env:PORT = '5319'
npm run dev
```

上述环境变量会影响当前 PowerShell 窗口中随后启动的服务。

## 第一次游玩

1. 在 $Z\leq0$ 的当前工作面点击格点摆子，或选择“无限填满”。
2. 用 Y 加减按钮、数字输入或滑条切换工作面，编辑其他位置。
3. 点击“开始跳棋”，选择实心棋子，再直接点击亮起的落点，包括 ±Y 跨层落点。
4. 灰色落点被其他落点遮挡；旋转到它完全露出，或者使用六向按钮。

“自动跟随”位于跳跃控制区，默认打开。关闭后，跳跃和撤回都保持当前切片和视图位置；手动切片与坐标定位仍正常工作。

游戏默认进入空白蓝图。

## 操作速查

| 操作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 摆子、选子 | 左键轻点当前工作面 | 单指轻点当前工作面 |
| 旋转视角 | 默认左键拖动；右键拖动始终旋转 | 默认单指拖动 |
| 平移工作区域 | 切换“平移”后左键拖动；或 Shift + 拖动／中键拖动 | 切换“平移”后单指拖动；或双指拖动 |
| 缩放 | 滚轮或缩放按钮 | 双指捏合或缩放按钮 |
| 切换 Y 工作面 | 加减按钮、数字输入、附近切片滑条 | 相同 |
| 六向跳跃，包括跨 Y | 直接点击亮色落点，或按方向按钮 | 相同 |
| 恢复容易点选的角度 | “正视”按钮 | 相同 |
| 回到原点附近及初始视角 | “归位”按钮 | 相同 |

棋子只在**当前工作面**接受画布点选。空心的邻层棋子用于理解空间关系，不接受点选。侧视时暂停普通摆子／选子，已选棋子的可见落点仍可以直接点击。旋转不会改变所绘制的 X/Z 格点范围；平移、缩放和窗口尺寸变化才会改变这一范围。

用 `Tab` 聚焦棋盘，或先点击棋盘，即可使用以下按键。输入框、按钮拥有焦点时保留其通常的键盘行为。

| 按键 | 操作 |
| --- | --- |
| ← / → | 光标沿 X 轴减一／加一 |
| ↑ / ↓ | 光标沿 Z 轴加一／减一 |
| 空格 / Enter | 操作光标所在格点 |
| Q / PageUp | Y 工作面减一 |
| E / PageDown | Y 工作面加一 |
| W / A / S / D | 平移视图 |
| + / =，− / _ | 放大／缩小 |
| F | 正视当前工作面 |
| H | 归位 |
| Esc | 取消选子和光标；弹窗中关闭弹窗 |

桌面的“坐标定位”可直接输入 X、Y、Z，将指定格点居中并正视当前工作面。

## 规则与对局

每一跳都沿某个坐标轴移动两格：起点与中间一格有棋子，落点为空。跳跃后移除中间棋子，棋子总数减少一枚；不允许斜跳。

“撤回一步”恢复上一步，开启自动跟随时还会切回原工作面；“重玩这局”恢复开局布局；“回到蓝图”恢复开局并允许重新编辑。替换已有布局或清除已走棋谱前，会显示确认弹窗。走棋后会清除选中状态。

“最高层”记录当前这条棋谱曾到达的最高层，撤回也会相应恢复记录。有限开局显示当前／开局棋子数；无限开局显示下方空格与上方棋子数。

第 7 层可达、第 8 层不可达来自数学规则，引擎没有额外禁止向第 8 层移动。证明与一手文献出处见 [数学说明](./docs/MATHEMATICS.md)。更完整的交互设计说明见 [交互设计](./docs/INTERACTION.md)。

## 离线方式与数据

代码、图形和音效全部来自项目本地，没有 CDN、在线字体、后端、账号或网络服务依赖。**启动本地 HTTP 服务后，即使没有互联网，也能正常游玩。** 手机访问仍需要能够连接运行服务的电脑。

请通过 HTTP 打开。浏览器对 ES Module 的安全限制意味着不能通过双击 `index.html`、使用 `file://` 运行。项目没有 Service Worker 或离线安装缓存；关闭本地服务后，不能依靠离线缓存重新打开游戏。

对局与声音偏好只保存在当前页面内存中，刷新或关闭页面会重置。声音默认开启，在第一次用户操作后解锁；浏览器无法播放声音时不影响规则和操作。

## 构建与检查

```powershell
npm test
npm run build
npm run preview
```

`npm test` 只运行本项目的三维版本测试。`npm run build` 清空并重新生成本项目的 `dist/`，复制游戏页面、源码与本地音效，避免携带旧文件；`npm run preview` 用同一个本地 HTTP 服务提供该目录。预览前停止已占用同一端口的开发服务，或设置另一个 `PORT`。静态文件可交给普通静态 HTTP 服务器提供，无需服务端运行逻辑。

博客的集成与部署从仓库根目录运行对应命令，具体见 [仓库说明](../../README.md)。根构建会自动重新生成本项目的 `dist/` 并集成其中的运行文件，无需预先手动构建子项目。独立运行时，说明窗口中的版本链接跳转到正式博客；博客集成后，该链接使用同源项目地址。

自动跟随、六向直接点选、遮挡恢复和侧视范围均有回归覆盖。开发阶段的浏览器验证及真机测试范围见 [验证记录](./docs/VALIDATION.md)。

## 代码结构

```text
index.html                    三维游戏入口、控制面板与弹窗
src/
  engine.js                   三维规则、无限半空间、快照、历史与规则测试用棋谱
  camera.js                   正交投影、工作面逆投影、视角与可见窗口
  gestures.js                 点击／拖动分离和多指导航状态
  renderer.js                 Canvas 三维投影、当前面与邻层、坐标和落点
  app.js                      界面状态、六向控制、键盘、确认与自动跟随
  styles.css                  桌面／移动布局、安全区和弹窗样式
  audio.js                    本地音效、静音和不可用时的降级
  webmcp.js                   自动检测支持的可选浏览器代理接口
  mark.svg                    本地矢量标志
sounds/                       本地 WAV 音效
scripts/                      无依赖本地服务与静态构建脚本
tests/                        三维版本测试
docs/                         数学与交互设计说明
```

渲染每帧最多遍历当前 XZ 窗口的 $31\times31$ 个格点、前后合计最多 5 个 Y 层。这个窗口限制控制显示成本；窗口之外的棋子仍然存在并参与规则。相机和定位控件有约 $\pm10^6$ 格的工程保护边界，规则引擎使用更大的 JavaScript 安全整数坐标范围，均不把可达高度硬编码为 7。
