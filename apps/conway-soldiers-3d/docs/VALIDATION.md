## 浏览器检查

本轮检查了 320×568、390×844、844×390 和 1440×900 的 CSS 视口及应用默认面板尺寸。未发现横向页面溢出。窄竖屏允许页面滚动；短横屏的中间控制区可滚动，固定的对局按钮仍可操作。测试结束已恢复默认浏览器视口。

实际浏览器操作确认：

1. 在无限填满的局面中创建六个合法落点，选择棋子后，六个标签与右侧按钮按 X 橙、Y 蓝、Z 绿对应显示。
2. 在桌面与手机视口直接点击 +Y 圆完成跳跃。关闭自动跟随后，棋子到达 Y=2，工作切片仍为 Y=0，观察中心与角度保持不变；撤回同样保留视图。
3. 旋转使落点重叠，后方目标呈灰色虚线；部分显露时保持灰色，继续旋转使其完全露出后恢复。
4. 绕到背面后，邻层图例和棋盘中的远近实虚线交换，蓝／紫所代表的世界 Y 方向保持不变。
5. 侧视提示位于画布角落；主棋盘中心可继续观察和操作明确可见的落点。
6. 手机的自动跟随开关和六向按钮可见；短横屏可以滚动到跟随开关并切换状态。
7. 构建页面加载正常，浏览器错误／警告记录为空。
