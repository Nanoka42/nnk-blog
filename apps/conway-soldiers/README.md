# 康威跳棋 · Conway’s Soldiers

一个直接进入无限棋盘的中文 H5 游戏。使用原生 JavaScript、Canvas 2D 和 CSS，没有第三方运行依赖，也没有后端、账号、埋点或持久化存储。所有图标和音效从本项目加载，不请求字体服务或 CDN。

本项目位于博客仓库的 `apps/conway-soldiers/`，可独立运行；[三维版本](../conway-soldiers-3d/) 是并列的独立项目。博客正式入口为 [康威跳棋](https://nanoka.tv/projects/conway-soldiers/)，两个游戏的说明窗口可以互相跳转。

## 本地运行

电脑安装 Node.js 20.11 或更新版本后，在本目录运行：

```powershell
npm run dev
```

打开终端给出的地址，默认为 `http://127.0.0.1:4173/`。不需要运行 `npm install`。请通过 HTTP 打开；浏览器的 ES Module 安全机制不支持直接双击 `index.html` 的 `file://` 用法。

如果要用同一局域网的手机访问开发服务：

```powershell
$env:HOST = '0.0.0.0'
npm run dev
```

手机访问电脑局域网 IP 的 4173 端口；开发服务只供本地调试。默认仅监听本机。端口占用时可用 `$env:PORT = '4174'` 修改。

## 已实现的玩法

- 默认空白蓝图，只能在 $y\leq0$ 的格子放置或移除棋子。
- 清空、数学意义上的无限填满；已有布局时弹出确认，默认焦点在取消。
- 四方向单子跳吃、落点提示、切换选择与取消选择；走棋后不继续选中落地棋子。
- 开局快照、回到开局蓝图、重玩和逐步撤回；有走棋历史时确认恢复。
- 有限模式显示当前 / 开局棋子数及步数；无限模式显示无限棋子数、步数，并区分下方空格与上方棋子。
- 深浅木色格子、凹面圆棋子、红色 $x=0$ 列、绿色 $y=0$ 行；原点格为深色。
- 蓝图可编辑区的蓝色调网格、不可编辑区斜线；无限棋盘边缘渐隐并轻微模糊，坐标标签位于渐隐区域外。
- 坐标始终留在视口边缘，缩放时按 $1,2,5,10,20,50,\dots$ 间隔显示，避免碰撞。
- 鼠标拖动、滚轮锚点缩放；单指轻点 / 拖动分离，双指平移缩放，抬起一指不会误落子。
- 默认视图的 0.1–5 倍缩放。原点不在棋盘可见区域内时才启用归位按钮。
- 本地音效、静音开关、规则与署名信息页；操作不添加落子或跳跃动画。
- 手机安全区、动态视口高度、模态弹窗焦点管理、键盘操作及基础读屏反馈。

声音默认开启。浏览器要求用户操作后才能启动音频，游戏会在首次触摸、点击或按键时解锁；音频不可用时仍可正常游玩。刷新后，布局、历史和静音偏好均重置。

## 键盘操作

用 Tab 聚焦棋盘，或先点击棋盘：

| 按键 | 操作 |
|---|---|
| 方向键 | 移动棋盘光标 |
| 空格 / 回车 | 操作光标所在格子 |
| Esc | 取消选择和光标；在弹窗中关闭弹窗 |

### 无限状态的表示

基准函数为 $b(x,y)=\text{full}\land(y\leq0)$，有限差异集合为 $D$：

$$
\operatorname{occupied}(x,y)=b(x,y)\oplus[(x,y)\in D].
$$

验证起点与中点有子、终点为空、距离为正交两格后，翻转三格在 $D$ 中的成员关系。撤回再次翻转同样三格。开局快照复制集合，不与活动棋盘共享引用。

无限模式下，$D$ 包括 $y\leq0$ 的空格 $H$ 和 $y>0$ 的棋子 $P$。若开局空格数为 $H_0$，每一步都满足 $H-P=H_0+\text{steps}$，因此不能把 `differences.size` 当作空格数。

渲染采用缓存的木纹与棋子图案。满棋盘的基准由 Canvas 重复图案绘制，再修正有限差异，不枚举或创建无限棋子。只在状态或视图变化时请求下一帧。高 DPI 绘制倍率上限为 2.5，控制手机显存和绘制成本。

棋盘规则没有预设行数限制；相机仅为浮点精度设置约 $\pm10^9$ 格的工程保护边界。第五行不可达来自数学规则，不是代码禁止点击第五行。

### 验证

```powershell
npm test
```

测试包含用户提供的 5 份完整棋谱：2、4、8、20、21 枚棋子分别经 1、3、7、19、20 跳抵达对应目标；还覆盖有限 / 无限计数不变量、全部撤回、快照隔离、无效移动的原子性、7 种屏幕尺寸下的相机数学、缩放上下限、手势取消与双指抬起防误触，以及实际界面事件处理器的状态流程。

界面集成测试使用 DOM / Canvas 测试替身，不等同于浏览器布局测试。尚未在 iOS Safari、Android Chrome 真机上验收；真实声音播放、字体排版、浏览器手势竞争及系统中断恢复仍需真机验证。实验性 WebMCP 在无支持浏览器中直接跳过，其注册测试替身也不代表真实协议环境验收。

`npm run build` 清空并重新生成本项目的 `dist/`，避免携带旧文件；源码本身就能作为静态网页运行。项目没有云平台 SDK、服务端路由或特定主机配置。

博客的集成与部署从仓库根目录运行对应命令，具体见 [仓库说明](../../README.md)。根构建会自动重新生成本项目的 `dist/` 并集成其中的运行文件，无需预先手动构建子项目。独立运行时，说明窗口中的版本链接跳转到正式博客；博客集成后，该链接使用同源项目地址。
